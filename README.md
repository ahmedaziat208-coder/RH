# 🍽️ OBAYOLI - نظام إدارة رواتب وموظفي المطاعم بالمغرب (RH & Paie Maroc)

نظام إلكتروني لإدارة الموارد البشرية للمطاعم والمقاهي، مع جدول رواتب مبسط بالدرهم المغربي (MAD / د.م)، الحضور، وصندوق البقشيش.

---

## 🌟 المميزات الرئيسية

1. **جدول أسماء الموظفين (Liste des Salariés)**:
   - عرض فوري وشامل لبيانات الموظفين: **الاسم الكامل**، **POSTE**، **الراتب الشهري (د.م)**، **رقم الهاتف**، **رقم البطاقة الوطنية (CIN)**، و**تاريخ الدخول**.
   - أزرار **تعديل** و**حذف** فورية في الجدول.
   - تتبع تواريخ صلاحية الشهادات الطبية الصحية (**Carte Sanitaire**) لتجنب مخالفات لجان المراقبة الصحية.

2. **جدول الرواتب وبيان الراتب**:
   - إضافة الموظفين تلقائيًا من قائمة الموظفين بعد احتساب الشهر.
   - الراتب اليومي = الراتب الشهري ÷ 26.
   - تُدخل أعداد أيام المرض والغياب وDouble Shift وأيام عمل الراحة، ومبلغ التسبيق، يدويًا في صف الموظف.
   - الراتب الصافي = الراتب الشهري − خصم المرض − خصم الغياب − التسبيق + بدل Double Shift + بدل عمل يوم الراحة. كل يوم/وردية محسوبة بقيمة الراتب اليومي.
   - تعديلات الجدول محفوظة تلقائيًا، وتُحدّث قسيمة الراتب والتصدير CSV.
   - لا تخصم المعادلة CNSS أو AMO أو IR، ولا تُدرج البدلات أو العلاوات أو الجزاءات الأخرى.

3. **حضور وشفتات العمل (Pointage & Heures Supplémentaires)**:
   - تسجيل أوقات الدخول والخروج اليومية والساعات الإضافية؛ لا تدخل ساعات العمل الإضافية في معادلة الراتب المبسطة الحالية.
   - أزرار تعديل وحذف تسجيلات الحضور اليومية.

4. **صندوق البقشيش المشترك (Pourboires Pool)**:
   - تجميع إكراميات الزبائن وتوزيعها (بالتساوي أو وفق نقاط الأقسام: صالة، مطبخ، بار).
   - إدارة مستقلة عن جدول الرواتب؛ لا تدخل حصص البقشيش في معادلة الراتب الحالية.

5. **التسبيقات والبدلات والخصومات (Acomptes & Sanctions)**:
   - تُحمّل التسبيقات المعتمدة للشهر إلى جدول الرواتب عند احتسابه، ويمكن تعديل مبلغ التسبيق يدويًا في صف الموظف.
   - تُسجل المكافآت والخصومات في هذا القسم، لكنها لا تدخل في معادلة الراتب المبسطة الحالية.

6. **محرك قاعدة البيانات DATABEST**:
   - حفظ تلقائي مستمر وفوري للبيانات محلياً بدون خادم خارجي.
   - تصدير واستيراد النسخ الاحتياطية بصيغة **JSON (Backup & Restore)**.

---

> **تنبيه مهم:** جدول الرواتب الحالي يستخدم معادلة إدارية مبسطة حسب الإعداد المطلوب، ولا يحتسب اقتطاعات CNSS أو AMO أو IR؛ لذلك لا يُعدّ بيان الراتب بديلًا عن قسيمة قانونية أو مسير محاسبي معتمد. راجع محاسبًا مغربيًا قبل استخدامه للصرف الرسمي أو التصريحات.

## 🛠️ التقنيات المستخدمة

- **React 19** + **TypeScript**
- **Vite 8**
- **Tailwind CSS 4**
- **Lucide Icons**
- **DATABEST Engine** (Local reactive persistent storage)

## 🚀 التشغيل المحلي (Local Setup)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build
```

## 📦 الرفع والربط مع مستودع GitHub

لرفع المشروع على حسابك في GitHub، اتبع الخطوات التالية:

```bash
# 1. أنشئ مستودعاً جديداً فارغاً على GitHub باسم obayoli-restaurant-hr
# 2. أضف الرابط البعيد لمستودعك (استبدل الرابط برابط مستودعك):
git remote add origin https://github.com/USERNAME/obayoli-restaurant-hr.git

# 3. ارفع المشروع إلى الفرع الرئيسي main:
git branch -M main
git push -u origin main
```
