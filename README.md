# 🍽️ OBAYOLI - نظام إدارة رواتب وموظفي المطاعم بالمغرب (RH & Paie Maroc)

نظام إلكتروني متكامل وشامل مخصص للمطاعم والمقاهي في **المملكة المغربية** لإدارة الموارد البشرية (RH)، مسير الرواتب بالدرهم المغربي (MAD / د.م)، حضور وشفتات العمل، صندوق البقشيش (Tips / Pourboires)، وتسبيقات الأجور ومطابقة معايير **CNSS** و**AMO** والضريبة على الدخل **IR**.

---

## 🌟 المميزات الرئيسية

1. **جدول أسماء الموظفين (Liste des Salariés)**:
   - عرض فوري وشامل لبيانات الموظفين: **الاسم الكامل**، **POSTE**، **الراتب الشهري (د.م)**، **رقم الهاتف**، **رقم البطاقة الوطنية (CIN)**، و**تاريخ الدخول**.
   - أزرار **تعديل** و**حذف** فورية في الجدول.
   - تتبع تواريخ صلاحية الشهادات الطبية الصحية (**Carte Sanitaire**) لتجنب مخالفات لجان المراقبة الصحية.

2. **مسير الرواتب وقسيمة الأجر الرسمية (Bulletin de Paie)**:
   - يعرض جدول الرواتب الموظفين المسجلين تلقائياً بالاسم والوظيفة والراتب الأساسي؛ وتظهر الحالة "غير محتسب" إلى أن يُحتسب راتب الشهر.
   - احتساب آلي للأجر الإجمالي الخام (Salaire Brut) واقتطاعات الضمان الاجتماعي **CNSS (4.48% وبسقف اشتراك 6,000 د.م)** والتأمين الإجباري **AMO (2.26%)** والضريبة على الدخل **IR** وفق شرائح 2025.
   - احتساب علاوة الأقدمية حسب مدة الخدمة الفعلية: 5% بعد سنتين، 10% بعد 5 سنوات، 15% بعد 12 سنة، 20% بعد 20 سنة، و25% بعد 25 سنة.
   - إدراج علاوة الأقدمية (Prime d'ancienneté) ومنحة القفة (Panier) وتعويض النقل (Transport).
   - نموذج ورقة أداء رسمية جاهزة للطباعة المباشرة على مقاس **A4** مع خانات التوقيع والختم والمبلغ بالحروف بالدرهم المغربي.
   - تصدير مسير الرواتب كاملاً إلى ملف **Excel (CSV)**.

3. **حضور وشفتات العمل (Pointage & Heures Supplémentaires)**:
   - تسجيل أوقات الدخول والخروج اليومية والساعات الإضافية وربط الساعات المسجلة فقط بالمسير الشهري (لا تُنشأ ساعات إضافية افتراضية).
   - أزرار تعديل وحذف تسجيلات الحضور اليومية.

4. **صندوق البقشيش المشترك (Pourboires Pool)**:
   - تجميع إكراميات الزبائن وتوزيعها (بالتساوي أو وفق نقاط الأقسام: صالة، مطبخ، بار).
   - ترحيل فوري لمبالغ البقشيش إلى قسيمة الراتب.

5. **التسبيقات والبدلات والخصومات (Acomptes & Sanctions)**:
   - تسجيل طلبات التسبيق المالي على الراتب وخصمها آلياً في شهر الاستحقاق المحدد.
   - تسجيل مكافآت التميز والخدمة وخصومات كسر الصحون والأواني والتأخيرات.

6. **محرك قاعدة البيانات DATABEST**:
   - حفظ تلقائي مستمر وفوري للبيانات محلياً بدون خادم خارجي.
   - تصدير واستيراد النسخ الاحتياطية بصيغة **JSON (Backup & Restore)**.

---

> **تنبيه:** هذا التطبيق أداة إدارية تجريبية وليس برنامج محاسبة معتمدًا. قواعد الأجور والضرائب والإعفاءات والساعات الإضافية قد تعتمد على العقد والظروف القانونية؛ راجع محاسبًا مغربيًا قبل اعتماد قسائم الأداء أو التصريحات الرسمية.
> تُحتسب الأجور اليومية والساعية من سجلات الحضور، وتُخفض أجور الموظفين الشهريين فقط عند تسجيل غياب صريح (وفق أساس 26 يومًا في الشهر). الإعفاءات المطبقة على تعويضات الوجبة والنقل والخصومات الأخرى تحتاج مراجعة حسب الحالة.

## 🛠️ التقنيات المستخدمة

- **React 19** + **TypeScript**
- **Vite 8**
- **Tailwind CSS 4**
- **Lucide Icons**
- **DATABEST Engine** (Local reactive persistent storage)

## 🚀 التشغيل المحلي (Local Setup)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build
```

## 📦 الرفع والربط مع مستودع GitHub

لرفع المشروع على حسابك في GitHub، اتبع الخطوات التالية:

```bash
# 3. ارفع المشروع إلى الفرع الرئيسي main:
git branch -M main
git push -u origin main
```
